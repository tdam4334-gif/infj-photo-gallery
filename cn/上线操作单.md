# 国内上线操作单（实名后约 15 分钟）

> 风险：实名信息只能你本人填；公开上传无审核；绑自己的域名做网站一般要 ICP 备案。
> 只用 `http://公网IP:8765` 通常不用备案。

## 一、注册实名（你来做）

**推荐腾讯云**：

1. https://cloud.tencent.com → 注册/登录  
2. 账号实名认证  
3. 购买 **轻量应用服务器**  
   - 地域：广州/上海/北京  
   - 2核2G 起，镜像 Ubuntu 22.04  
   - 设置 root 密码  
4. 控制台 → 防火墙 → 放行 **TCP 8765**

阿里云轻量/ECS 亦可。

## 二、部署

### A. 把 SSH 信息发我，我来装

```
公网IP：
用户名：root
密码：（发完建议改一次）
```

### B. 自己执行

把 `cn/` 传到服务器后：

```bash
sudo bash install.sh
```

看到 `访问: http://x.x.x.x:8765` 即成功。

## 三、发给国内朋友

```
心隅 · INFJ 照片收藏馆（国内）
http://你的公网IP:8765
```

- 外网：https://infj-gallery.infj-gallery.workers.dev  
- 两套数据默认不互通  

## 五、以后要国内国外同一面墙

再做同步或统一后端。
